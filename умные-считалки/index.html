Магия фигур — геометрия

Считалки для площадей, периметров и объёмов фигур.

Прямоугольник

S = a·b, P = 2(a + b)

Треугольник

S = ½ · a · h

Круг

L = 2πr, S = πr²

Теорема Пифагора

c = √(a² + b²)

Параллелепипед

V = a·b·c, S = 2(ab + ac + bc)

Формулы-помощники — алгебра

Уравнения, прогрессии и проценты — всё считается по коэффициентам.

Квадратное уравнение

ax² + bx + c = 0 → ищем D и корни

Арифметическая прогрессия

aₙ = a₁ + d(n−1), Sₙ = (a₁ + aₙ)/2 · n

Проценты

X% от числа Y = X/100 · Y

Степень

base ^ exp

Законы в одну кнопку — физика

Классические школьные формулы физики в формате быстрых считалок.

Скорость

v = s / t

Сила (2-й закон Ньютона)

F = m·a

Плотность

ρ = m / V

Работа и мощность

A = F·s, N = A / t

Закон Ома

I = U / R
