Магия фигур — геометрия

Калькуляторы площадей, периметров и объёмов фигур.

Прямоугольник

Площадь S = a · b, периметр P = 2 · (a + b)

Треугольник

Площадь S = ½ · основание · высота

Круг

Длина окружности L = 2πr, площадь S = πr²

Теорема Пифагора

Гипотенуза c = √(a² + b²)

Параллелепипед

Объём V = a · b · c, площадь поверхности S = 2(ab + ac + bc)

Помощник по алгебре

Уравнения, прогрессии, проценты и степени — всё считается по коэффициентам.

Квадратное уравнение

ax² + bx + c = 0 → ищем дискриминант D и корни x₁, x₂

Арифметическая прогрессия

aₙ = a₁ + d(n−1), сумма Sₙ = (a₁ + aₙ)/2 · n

Проценты

Сколько будет X процентов от числа Y: ответ = X : 100 · Y

Степень числа

Возводим число a в степень n, например: 2¹⁰ = 1024

Законы физики в одну кнопку

Классические школьные формулы физики в формате быстрых калькуляторов.

Скорость

v = s : t

Сила (2-й закон Ньютона)

F = m · a

Плотность

ρ = m : V

Работа и мощность

A = F · s, затем N = A : t

Закон Ома

I = U : R
